# C Programming Practice — Physical AI Engineer Course

C language exercises from the first module of the **Physical AI Engineer**
course at the **KCCI Seoul Technology Education Center**.

The exercises focus on building fundamental C skills. While the problems
themselves are basic, they are framed around robotics-themed scenarios —
such as analyzing robot state or handling actuation logic — to stay close
to the kind of situations one might encounter when working with robots.

## Structure

Each folder is named by the date of the practice session. Inside, the
exercises are numbered simply (e.g. `0914_1.c`, `0914_2.c`).
```
├── 0914/
│ ├── 0914_1.c
│ ├── 0914_2.c
│ └── ...
├── 0915/
│ └── ...
```
Each source file includes comments describing the problem definition and
a short note on the related robotics concept.
